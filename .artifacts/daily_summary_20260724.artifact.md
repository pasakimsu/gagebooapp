## 1. 실시간 푸시 알림 및 PWA 도입
*   **PWA(Progressive Web App)**: 웹사이트를 스마트폰에 앱처럼 설치할 수 있는 기능 추가 (`manifest.ts`, 서비스 워커 설정).
*   **FCM(Firebase Cloud Messaging)**: 일정 등록 시 가족 기기에 실시간 알림이 전송되는 인프라 구축.
*   **iOS 최적화**: 아이폰 사파리 PWA 규격에 맞춘 서비스 워커 및 알림 페이로드(`mutable-content` 등) 적용.
*   **알림 관리**:
    *   일반 사용자: 알림 ON/OFF **토글 스위치** 제공.
    *   관리자(`admin`): 시스템 점검용 **[전송 테스트]** 버튼 제공.

## 2. 일정 관리 기능 고도화
*   **지능형 일괄 삭제**: 일정 목록에서 각 항목 옆에 [삭제] 버튼 추가. 여러 날짜에 걸친 일정 삭제 시 "전부 삭제" 여부를 묻는 확인 창 추가.
*   **메시지 상세화**: 알림 메시지에 등록자, 날짜, 일정 내용이 포함되도록 개선.
*   **시각적 가독성**: `bak` 님의 일정 글자색을 **에메랄드 그린(Emerald Green)**으로 변경하여 가독성 향상.

## 3. 대시보드 UI/UX 개편
*   **통합 레이아웃**: 메뉴 버튼과 일정 영역을 하나의 큰 사각형 안에 통합하여 공간 활용도 극대화.
*   **좌측 사이드바**: 주요 메뉴(일정, 계산기, 부조, 대출, 지출)를 좌측에 세로로 배치하여 전문적인 대시보드 느낌 구현.
*   **메뉴 추가**: `/expenses` 경로로 연결되는 **[지출]** 버튼 신규 추가.

## 4. 계산기 기능 및 UI 최적화
*   **이중 테이블**: '입력 금액(수당/월급)' 표와 '배분 결과' 표를 분리하여 데이터 흐름을 명확히 함.
*   **실시간 미리보기**: '저장' 전에도 '계산하기'만 누르면 하단 표에 즉시 반영되는 기능 추가.
*   **모바일 초슬림 최적화**: 폰 화면에서 가로 스크롤 없이 한눈에 표를 볼 수 있도록 여백 및 폰트 크기(`11~12px`) 정밀 조정.
*   **데이터 호환성**: 날짜 형식 차이로 인해 이전 데이터가 안 보이던 현상 해결(Restoration).
