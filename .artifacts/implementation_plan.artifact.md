# 일정 일괄 삭제 기능 도입 계획

사용자가 지정한 날짜 범위(예: 1일~3일) 내의 모든 일정을 한 번에 지울 수 있는 **일괄 삭제** 기능을 추가합니다.

## User Review Required

> [!WARNING]
> 일괄 삭제 기능을 실행하면 **해당 기간에 등록된 본인 및 배우자의 모든 일정**이 한꺼번에 삭제됩니다. (단, 자동 등록된 기념일은 제외됩니다.)
