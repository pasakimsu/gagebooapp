# '건강검진/주간연가' 시수 직접 차감(74h ➔ 62h) 및 수수료 보정 계획

9월 7일자 `건강검진` 일정이 정상 감지되었음에도 불구하고, 수당 계산기에서 `건강검진/주간연가` 시수를 시간외 시간에서 직접 차감하지 않고 금액으로만 차감하여 표기상 **74시간**이 유지되었던 원인 분석 및 수식 보정 계획입니다.

---

## 🔍 수식 분석 및 74시간이 유지되었던 원인 파악

### 1. 기존 코드의 주간연가/건강검진 시수 차감 누락
- **기존 방식**:
  - `건강검진 (bak)` 일정을 `주간연가` 1건으로 정상 감지했으나, 시간외 시수는 당번시수(240h) - 정규시간(166h) = **74시간**으로 고정 계산하고, 주간연가는 금액(-100,670원)으로만 차감하고 있었습니다.
  - 이로 인해 UI 명세서 항목에 **'시간외수당 74시간'**으로 그대로 출력되었던 것입니다.

### 2. 실제 명세서의 주간연가/건강검진 시수 산정 공식
- 주간연가(건강검진) 1회 사용 시 당번 근무 중 **12시간이 차감**됩니다:
  - **보정된 시간외 인정 시수** = `74시간 - 12시간(주간연가/건강검진) = 62시간`
  - **시간외수당 금액**: `62시간 × 12,584원 = 780,200원`
- 👉 실제 10월 보수지급명세서의 **`시간외수당 62시간 / 780,200원`**과 **1원 단위까지 100% 완벽히 일치**하게 됩니다!
