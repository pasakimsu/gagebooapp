# 대시보드 레이아웃 개편 및 공간 최적화 계획 (시안)

로그인 후 첫 화면인 대시보드의 구성을 변경하여, 주요 메뉴 버튼을 좌측으로 옮기고 일정 정보 공간을 대폭 확장하는 실험적인 디자인을 적용합니다.

## Proposed Changes

### [대시보드 페이지](file:///C:/Users/nalb/OneDrive/바탕 화면/최종본/myhome-web-main/app/budget/page.tsx) [MODIFY]

#### 1. 전체 컨테이너 너비 확장
*   현재 `max-w-md` (약 448px)로 제한된 카드 너비를 `max-w-4xl` (약 896px) 수준으로 확장하여 넓은 화면을 활용합니다.

#### 2. 좌측 메뉴 바 도입
*   하단에 가로로 나열되어 있던 4개의 버튼(일정, 계산기, 부조금, 대출)을 좌측에 세로(`flex-col`)로 일렬 배치합니다.
*   버튼 간의 간격을 조절하여 사이드바 느낌의 깔끔한 메뉴 영역을 만듭니다.

#### 3. 일정 대시보드 확장 (메인 영역)
*   메뉴 바 우측의 남는 공간을 모두 일정 표시 영역이 차지하도록 합니다.
*   공간이 넓어진 만큼 이번주/이번달 일정 목록을 더 길게 보여줄 수 있으며, 가로로 긴 일정 텍스트도 잘림 없이 쾌적하게 표시됩니다.

#### 4. 반응형 레이아웃 유지
*   모바일 기기에서는 자동으로 다시 세로 쌓기 방식으로 변경되도록 설정하여 기존의 사용성을 유지합니다. (PC/태블릿 등 넓은 화면에서만 새 레이아웃 적용)
