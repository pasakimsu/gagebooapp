# 부조금 검색 알고리즘 정교화 계획 (v2)

검색 결과가 너무 광범위하게 나오는 문제를 해결하기 위해, 낱개 글자 비교 방식에서 **연속된 2글자 이상 일치(N-gram 매칭)** 방식으로 알고리즘을 업그레이드합니다.

## Proposed Changes

### [SearchDonations 컴포넌트](file:///C:/Users/nalb/OneDrive/바탕 화면/최종본/myhome-web-main/app/Donations/components/SearchDonations.tsx) [MODIFY]

#### 1. 검색 알고리즘 고도화
*   **기존**: 낱개 글자가 2개 이상 겹치면 결과에 포함 (예: '김상구' vs '구조대우상봉' -> 상, 구 2글자 겹침 -> 검색됨)
*   **변경**: 검색어에서 **연속된 2글자 조각**을 추출하여, 이 조각들 중 하나라도 이름에 포함되어 있는지 확인합니다.
*   **핵심 로직**:
    *   검색어 '김상구' -> 조각들: ['김상', '상구']
    *   저장된 이름 '상구' -> '상구' 조각을 포함하므로 **매칭 성공**
    *   저장된 이름 '구조대우상봉' -> '김상'이나 '상구' 조각을 포함하지 않으므로 **제외**

#### 2. 상호 포함 관계 보장
*   검색어가 이름보다 긴 경우와 짧은 경우를 모두 고려합니다.
*   `A가 B를 포함함` 또는 `B가 A를 포함함`의 조건도 유지하여 검색 편의성을 확보합니다.
