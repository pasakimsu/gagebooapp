# 3조 1교대(당비비) 일정 공유 달력 연동 당월 예상 월급 계산 기능 구현 계획

일정 공유 달력 페이지(`/schedule`)에서 근무 패턴(당번-비번-비번) 및 작성된 일정 키워드(`주간연가`, `야간연가`, `당번연가`, `주간대기`, `야간대기`, `당번대기`), 2026년 소방공무원 계급별 수당 단가표를 연동하여 선택한 달의 예상 봉급 및 초과근무 수당을 자동으로 계산하는 우측 상단 라벨/배지식 대시보드 추가 계획입니다.

## User Review Required

> [!IMPORTANT]
> **상단 우측 라벨(배지) 배치 및 팝업 모달 방식**
> 1. **배치 위치**: **일정 공유 캘린더 페이지 (`/schedule`) 우측 상단 라벨**
>    - 달력 화면 우측 상단(헤더 영역)에 깔끔한 **컴팩트 라벨 배지**(`[ 💰 3월 예상 716만 원 ▼ ]`) 형태로 배치.
>    - 라벨 클릭 시 세부 수당 명세서 및 계급 선택이 담긴 **팝업 모달(Popover/Modal)**이 열려 달력 레이아웃을 전혀 가리지 않습니다.
> 2. **`bak` 계정 전용 접근 제어**:
>    - `localStorage.getItem("userId") === "bak"` (또는 admin) 계정 접속시에만 우측 상단 라벨 배지가 노출됩니다.
> 3. **2026년 수당 단가 데이터 적용**: `소방공무원_초과근무수당_2026.xlsx` 데이터(소방령~소방사 계급별 기본급, 시간외/야간/휴일 단가) 상수로 적용.
> 4. **달력 근무 패턴 및 연가/대기 일정 자동 감지**:
>    - **당번/비번 자동 분석**: 캘린더의 현재 선택 년/월의 당비비 패턴(`dutyStartDate` 기준)으로 평일 당번 횟수 및 휴일/공휴일 당번 횟수를 자동 스캔.
>    - **연가 일정 자동 집계**: 달력에 작성된 `주간연가`, `야간연가`, `당번연가` 일정을 자동 감지하여 수당 차감액에 반영.
>    - **대기/희망근무 일정 자동 집계**: 달력에 작성된 `주간대기`, `야간대기`, `당번대기` 일정을 자동 감지하여 추가 초과근무 수당에 반영.
