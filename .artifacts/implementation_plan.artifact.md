# 모달 UI 문구 변경 및 하단 버튼 분리 (등록 / 닫기) 구현 계획

모달 내 '연가 및 대기근무 횟수 수동 조절' 문구를 **'연가 및 대기근무 횟수 선택'**으로 변경하고, 모달 하단 버튼을 기존 단일 버튼에서 **[등록]**과 **[닫기]** 2개의 독립 버튼으로 분리하는 계획입니다.

---

## User Review Required

> [!IMPORTANT]
> **주요 UI 및 버튼 동작 변경 사항**
> 1. **문구 수정**:
>    - 기존: `⚙️ 연가 및 대기근무 횟수 수동 조절`
>    - 변경: `⚙️ 연가 및 대기근무 횟수 선택`
> 2. **하단 버튼 2개로 분리**:
>    - 기존: `[ 확인 및 닫기 ]` 단일 버튼
>    - 변경:
>      - **`[ 💾 등록 ]` 버튼**: 설정한 계급/호봉/수당/연가/대기 횟수 설정을 저장하고 모달을 닫습니다.
>      - **`[ ✖ 닫기 ]` 버튼**: 모달을 바로 닫습니다.


## Proposed Changes

### 1. `app/schedule/components/SalaryEstimateBadge.tsx` UI 수정
- 모달 내 어코디언 타이틀 텍스트를 `⚙️ 연가 및 대기근무 횟수 선택`으로 수정.
- 하단 버튼 영역을 2개 버튼으로 분리:
  - **`[ 💾 등록 ]` (호박색/초록색 전면 버튼)**: 수동 설정 및 횟수를 저장 후 모달 종료.
  - **`[ ✖ 닫기 ]` (회색 버튼)**: 창 닫기.
