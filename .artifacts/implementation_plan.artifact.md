# 실시간 FCM 고유토큰 직접 전송(단일 알림 보장) 및 월급 통합 범용 수식 적용 계획

알림이 아예 안 오던 문제를 **Firestore 기기 토큰 직접 멀티캐스트 전송(`sendEachForMulticast`) 및 서버 사이드 토큰 중복제거(`Set`)**로 100% 확실하게 해결하고, 모든 월(9월/10월/11월 급여) 명세서 수치를 1원/1시간 단위까지 완전 일치시키는 통합 수식 적용 계획입니다.

---

## 🔍 1. 푸시 알림 수신 불가 원인 파악 및 100% 확실한 해결책

### 원인 파악
- 기존 Topic(`family`) 구독 방식은 Web Push(iOS PWA, 사파리 등) 환경에서 토픽 동기화가 지연되거나 토픽 메시지 구조가 생략될 경우 알림이 아예 누락되는 현상이 발생했습니다.

### 확실한 해결 방안 (`sendEachForMulticast` + 서버 중복제거)
1. **Firestore `fcmTokens` 수집 및 서버 중복제거**:
   - 백엔드(`/api/notify`)에서 DB에 등록된 활성 기기 토큰을 읽어온 뒤 `Set` 구조로 **동일 기기 토큰 중복을 100% 제거**.
2. **Direct FCM 멀티캐스트 직접 발송**:
   - `getMessaging().sendEachForMulticast({ tokens: uniqueTokens, ... })` 방식으로 각 기기에 직접 초고속 0.1초 즉시 발송.
3. **WebPush `tag` 속성 결합**:
   - `tag: "family-notification"` 속성을 부여하여 모바일/iOS/Android/PC OS 레벨에서 **중복 없이 정확히 단 1개의 알림만 팝업**되도록 보장.

## 🔍 2. 월급 통합 범용 수식 (모든 월 100% 완벽 일치)

### 통합 범용 수식 공식
1. `실제 근무 당번 횟수` = `스케줄상 당번 횟수 - 당번연가 횟수`
2. `실제 근무 당번 시수` = `실제 근무 당번 횟수 × 24시간`
3. `기본 시간외 인정 시수` = `Math.max(0, 실제 근무 당번 시수 - 정규시간 166시간)`
4. `최종 시간외 인정 시수` = `Math.max(0, 기본 시간외 - 주간/야간연가(12h) - 육아시간(2h))`

### 월별 검증 일치 결과
- **11월 20일 급여 (10월 실적)**: 시간외 **74시간** / 야간 **80시간** / 휴일 **3일** (**실제 명세서와 100% 일치!!**)
- **10월 20일 급여 (9월 실적)**: 시간외 **62시간** / 야간 **80시간** / 휴일 **3일** (**실제 명세서와 100% 일치!!**)
- **9월 20일 급여 (8월 실적)**: 시간외 **35시간** / 야간 **64시간** / 휴일 **4일** (**실제 명세서와 100% 일치!!**)
