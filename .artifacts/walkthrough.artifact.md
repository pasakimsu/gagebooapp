# 부조금 검색 로직 고도화 완료

부조금 내역 검색 시 검색어와 이름 사이에 **2글자 이상 일치**하면 결과에 포함되도록 검색 알고리즘을 개선했습니다.

## 주요 변경 사항

### 1. 유연한 fuzzy 검색 알고리즘 적용
기존의 부분 일치 검색 방식에서 한 단계 나아가, 글자 집합 비교 방식을 도입했습니다.
*   **교집합 필터링**: 검색어와 저장된 이름 간에 겹치는 글자가 2개 이상이면 검색 결과로 판단합니다.
*   **예시**:
    *   '김상구' 검색 시 -> '상구' (상, 구 2글자 일치) 검색 성공
    *   '박철수' 검색 시 -> '김철수' (철, 수 2글자 일치) 검색 성공
    *   '상구' 검색 시 -> '김상구' (상, 구 2글자 일치) 검색 성공

### 2. 검색 정확도 향상
*   검색어와 저장된 이름의 앞뒤 공백을 자동으로 제거하여 검색 누락을 방지합니다.
*   이름 자체가 검색어를 포함하거나(`includes`), 검색어가 이름을 포함하는 경우도 빠짐없이 검색됩니다.

## 사용 방법
1.  부조금 페이지의 검색창에 검색할 이름을 **2글자 이상** 입력합니다.
2.  **검색** 버튼을 누르거나 **Enter**를 칩니다.
3.  겹치는 글자가 2개 이상인 모든 대상이 리스트에 나타납니다.
4.  나타난 이름 중 원하는 대상을 클릭하여 상세 내역(입금/출금)을 확인합니다.
