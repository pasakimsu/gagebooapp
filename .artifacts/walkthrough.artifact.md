# 계산기 UI 개선 및 실시간 데이터 시각화 완료

계산기 하단의 데이터 표시 방식을 요청하신 대로 이중 테이블 구조로 개편하고, 실시간 반응성을 강화했습니다.

## 주요 변경 사항

### 1. 이중 테이블 구조 도입
사용자별 입력 데이터와 계산 결과를 명확히 분리하여 표시합니다.
*   **상단 표 (입력 금액)**: 사용자별 '5일 수당', '20일 월급', 그리고 이 둘을 합친 '합계'를 보여줍니다.
*   **하단 표 (배분 결과)**: 원천 데이터를 기준으로 계산된 '생활비', '적금', '투자', '가족' 배분액을 보여줍니다.

### 2. 실시간 미리보기 기능
*   이제 '저장'을 누르기 전이라도, **'계산하기' 버튼을 클릭하는 즉시** 하단 표에 본인의 데이터가 반영됩니다.
*   이를 통해 배우자의 데이터와 본인의 현재 계산 결과를 즉석에서 비교해 볼 수 있습니다.

### 3. 시각적 가독성 개선
*   `bak` 님과 `yong` 님의 이름을 각각 **에메랄드 그린**과 **빨간색**으로 구분하여 표 안에서도 한눈에 누가 입력한 데이터인지 알 수 있게 했습니다.
*   합계 금액은 **황금색(#FFC90E)**으로 강조하여 중요도를 높였습니다.

## 테스트 방법
1.  계산기 페이지에서 이번 달(혹은 특정 달)을 선택합니다.
2.  수당과 월급을 입력하고 **'계산하기'**를 누릅니다.
3.  하단에 두 개의 표가 나타나며, 상단 표에는 입력한 금액이, 하단 표에는 배분된 금액이 실시간으로 표시되는지 확인합니다.
4.  내용이 맞다면 **'저장하기'**를 눌러 데이터를 확정합니다.
