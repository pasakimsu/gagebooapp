# 고정지출-대출 통합 관리 시스템 업데이트 완료

고정지출 관리 화면에 대출금 현황을 통합하여, 우리 집의 전체적인 지출 흐름을 한눈에 파악할 수 있도록 개선했습니다.

## 🚀 주요 업데이트 내용

### 1. 통합 대시보드 (📊 대시보드 탭)
*   **지출 합산**: '순수 고정지출'과 '대출 상환액'을 모두 더한 **[우리 집 총 지출]**액을 상단에 표시합니다.
*   **대출 섹션 추가**: 고정지출 카드 하단에 **[🏦 대출 상환 지출]** 섹션을 신설했습니다.
    *   주택담보대출, 박재현/김용휘 신용대출의 요약 정보를 대출 시스템과 동일한 디자인으로 보여줍니다.

### 2. 인별 상세 관리 (👤 박재현 / 👤 김용휘 탭)
*   **본인 명의 대출 연동**: 각자의 고정지출 리스트 하단에 **[💳 본인 명의 신용대출]** 카드를 배치했습니다.
*   **자동 동기화**: 대출 관리 시스템에서 정보를 수정하면 고정지출 화면에도 즉시 반영됩니다.

### 3. UI/UX 개선
*   **디자인 통일**: 대출 시스템의 시그니처 디자인(잔여 개월, 상환액 강조 등)을 그대로 가져와 일관성을 높였습니다.
*   **사용성 강화**: 지출 항목 상세보기 시 배경 터치로 닫기, 저장/삭제 버튼 위치 최적화 등을 적용했습니다.
